# Pensive v3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Subagents run on **Opus** (Gary's instruction).

**Goal:** Build Pensive v3, a decades-scale agent memory daemon, in the
existing pensive repo under `daemon/`, and earn the MCP-serving cutover
by beating the BM25 baseline on the real-query eval gate.

**Architecture:** One long-lived daemon owns a canonical SQLite store
(atoms, typed edges, provenance, facets, FTS5, model-keyed embeddings),
a hybrid recall engine (BM25 + dense + facets fused by RRF, cross-encoder
reranked, trust-scored), and ambient loops (briefer, distiller, drift
watcher). Embeddings are disposable derived data; canonical text and
edges outlive every model. Runs in parallel with the current stack;
cutover is gated on eval numbers.

**Tech Stack:** Runtime chosen by the Phase 0 spike (Go / TS-Bun /
Python-exception). SQLite (WAL) via the runtime's standard binding, FTS5
for BM25, ONNX Runtime for bge-small embeddings + bge-reranker, a
`VectorIndex` interface (flat scan now, usearch-HNSW later). The v2
Python library (MegaExtractor, boundary math, `research/head2head_eval.py`)
is imported/vendored, not rewritten.

## Global Constraints

- **Decades outranks all**: no canonical data is ever unrecoverable;
  embeddings are derived and rebuildable; schema is versioned and
  migrations are forward-only. Verbatim from spec section 1.
- **Language rule**: C/C++/TS or Go for prod; Go acceptable; Python only
  as a documented exception if the Phase 0 spike proves the no-Python
  paths infeasible. No Rust, ever.
- **No DIY auth**: localhost/tailscale bind now; Authelia forward-auth
  if ever web-exposed. Never roll sessions/hashing/RBAC.
- **Payload contract**: plain text, tiered, token-budgeted. No markdown
  furniture, no emoji, no AI-writing tells.
- **Compat during shadow**: existing MCP tool names
  (`pensive_recall`, `engram_emit_atom/discovery/failure/narrative/snapshot`,
  `pensive_analytics`) keep identical shapes; `pensive-recall` CLI keeps
  working through cutover.
- **Quality gate (cutover)**: recall R@10 >= 0.65 and MRR@10 >= 0.45 on
  `head2head_eval.py` (BM25 baseline 0.583 / 0.432), warm p95 recall
  <= 150 ms, superseded atoms never surface unchained, re-embed
  round-trip within 5% and zero canonical loss, kill -9 mid-write
  recovers clean, `pensive rebuild` round-trips byte-identical canon.
- **Test discipline**: deep-tests (risk model first, sabotage gate);
  verify only touched suites per task, full suite at phase gates only;
  never pin the CPU with concurrent pytest.
- **Thermal**: GPU-heavy work (embedding/rerank/re-embed) already drives
  the fan curve; pure-CPU phases need the GPU burn per the thermal rule.

- [ ] **Step 1: Write `schema.sql`** with exactly these tables (verbatim,
  this is the canonical contract):

```sql
PRAGMA journal_mode=WAL;
PRAGMA foreign_keys=ON;

CREATE TABLE IF NOT EXISTS meta (
  key TEXT PRIMARY KEY, value TEXT NOT NULL
);  -- holds schema_version

CREATE TABLE IF NOT EXISTS atoms (
  id           TEXT PRIMARY KEY,          -- ULID
  text         TEXT NOT NULL,
  kind         TEXT NOT NULL,             -- atom|narrative|snapshot|document_chunk
  project      TEXT,
  created_at   INTEGER NOT NULL,          -- unix seconds, when recorded
  occurred_at  INTEGER,                   -- when the remembered thing happened
  importance   REAL NOT NULL DEFAULT 0.0,
  status       TEXT NOT NULL DEFAULT 'live', -- live|superseded|tombstone
  schema_version INTEGER NOT NULL
);
CREATE INDEX IF NOT EXISTS idx_atoms_project ON atoms(project);
CREATE INDEX IF NOT EXISTS idx_atoms_created ON atoms(created_at);
CREATE INDEX IF NOT EXISTS idx_atoms_status  ON atoms(status);

CREATE TABLE IF NOT EXISTS provenance (
  id          TEXT PRIMARY KEY,           -- ULID
  atom_id     TEXT NOT NULL REFERENCES atoms(id),
  source      TEXT NOT NULL,              -- claude-code|codex|explicit-emit|bulk-import|distiller
  session_id  TEXT,
  agent       TEXT,
  source_ref  TEXT,                       -- transcript span/file/message id
  recorded_at INTEGER NOT NULL
);
CREATE INDEX IF NOT EXISTS idx_prov_atom ON provenance(atom_id);

CREATE TABLE IF NOT EXISTS edges (
  id            TEXT PRIMARY KEY,         -- ULID
  src_atom      TEXT NOT NULL REFERENCES atoms(id),
  dst_atom      TEXT NOT NULL REFERENCES atoms(id),
  type          TEXT NOT NULL,            -- supersedes|contradicts|causes|relates|same_thread
  weight        REAL NOT NULL DEFAULT 1.0,
  created_at    INTEGER NOT NULL,
  provenance_id TEXT REFERENCES provenance(id)
);
CREATE INDEX IF NOT EXISTS idx_edges_src ON edges(src_atom, type);
CREATE INDEX IF NOT EXISTS idx_edges_dst ON edges(dst_atom, type);

CREATE TABLE IF NOT EXISTS facets (
  atom_id TEXT NOT NULL REFERENCES atoms(id),
  key     TEXT NOT NULL,                  -- project|entity|tag|era
  value   TEXT NOT NULL,
  PRIMARY KEY (atom_id, key, value)
);
CREATE INDEX IF NOT EXISTS idx_facets_kv ON facets(key, value);

CREATE TABLE IF NOT EXISTS embeddings (
  atom_id    TEXT NOT NULL REFERENCES atoms(id),
  model_id   TEXT NOT NULL,
  vector     BLOB NOT NULL,               -- float32 little-endian
  embedded_at INTEGER NOT NULL,
  PRIMARY KEY (atom_id, model_id)
);

CREATE VIRTUAL TABLE IF NOT EXISTS fts USING fts5(
  text, content='atoms', content_rowid='rowid'
);
-- triggers keep fts in sync
CREATE TRIGGER IF NOT EXISTS atoms_ai AFTER INSERT ON atoms BEGIN
  INSERT INTO fts(rowid, text) VALUES (new.rowid, new.text);
END;
CREATE TRIGGER IF NOT EXISTS atoms_ad AFTER DELETE ON atoms BEGIN
  INSERT INTO fts(fts, rowid, text) VALUES ('delete', old.rowid, old.text);
END;
CREATE TRIGGER IF NOT EXISTS atoms_au AFTER UPDATE ON atoms BEGIN
  INSERT INTO fts(fts, rowid, text) VALUES ('delete', old.rowid, old.text);
  INSERT INTO fts(rowid, text) VALUES (new.rowid, new.text);
END;
```
